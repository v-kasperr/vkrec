# VKRec 🎙

Нативное macOS-приложение для записи встреч и звонков с расшифровкой, разбивкой по спикерам, саммари, отчётами по шаблонам и чатом по записям.

**Текущая версия: 1.6.0** · [Скачать DMG](VKRec-1.6.0.dmg) · [Руководство пользователя (PDF)](docs/VKRec-User-Manual.pdf)

---

## Возможности

- **Запись** — микрофон, системный звук (Zoom, Meet, звонки) или оба сразу. Во время записи бегущая лента уровня звука показывает, что микрофон действительно слышит — и в главном окне, и в плавающем индикаторе. Индикатор можно свернуть в компактную «линию с точкой» — при наведении курсора он разворачивается.
- **Предложение записи при звонке** — как только Zoom, Telegram, Meet или другое приложение займёт микрофон, VKRec предложит начать запись одним кликом (включается в настройках).
- **Живое превью** — текст появляется на экране по мере речи (локально, Apple Speech).
- **Точная расшифровка** — Whisper (OpenRouter), Deepgram или Gladia; последние два разбивают текст по спикерам: получается диалог «Спикер 1 / Спикер 2». Идёт в фоне на карточке записи — следующую запись можно начинать сразу. У реплик диалога есть таймкоды: клик перематывает плеер на реплику.
- **Запись не теряется** — аудио сохраняется в историю в момент остановки, до любых сетевых запросов; при ошибке провайдера или закрытии приложения расшифровку можно повторить кнопкой «Запустить заново».
- **Импорт** — окно «Импортировать запись…»: аудио- и видеофайлы (перетаскиванием или через ⌘O) и ссылки (YouTube, VK Видео, прямые ссылки — ⇧⌘L); несколько файлов можно склеить в одну запись.
- **Саммари** — краткое резюме + автоматическое название записи.
- **Отчёты по шаблонам** — 22 готовых шаблона в 5 категориях (итоги встречи, задачи, дейлик, планирование спринта, ретро, демо, встреча с клиентом, один-на-один, HR-интервью, PRD…) и свои шаблоны с категориями, иконками и цветами. Отчёт — оформленный документ с экспортом в PDF или простой текст; все сформированные отчёты сохраняются в записи, их можно переделать другим шаблоном. Автоотчёт после расшифровки — по желанию.
- **Чат по записи** — таб «Чат» на карточке: вопросы к содержанию конкретного разговора («что решили по срокам?», «что говорил второй спикер про бюджет?»). Модель отвечает только по расшифровке, ссылается на спикера и время, понимает уточняющие вопросы; три рекомендуемых вопроса подбираются автоматически. История чата и его стоимость сохраняются в записи.
- **Чат по записям** — кнопка в боковой панели: вопросы сразу к нескольким встречам — за сегодня, вчера, 7 дней, по тегу или к выбранным вручную. «Что обсуждали сегодня?», «Собери задачи», «Разбей по проектам» — ответ приходит потоком, оформлен как markdown и ссылается на конкретные встречи. Перед отправкой видна оценка стоимости; если записей слишком много, самые длинные заменяются саммари.
- **История** — все записи с аудио-плеером, поиском, тегами и фильтрами; поиск по тексту транскрипции на карточке (⌘F). В плеере — волна записи: видно, где говорили громко, а где пауза; клик или перетаскивание по волне перематывает.
- **Статистика** — на экране «Новая запись»: сколько записей и диалогов, сколько часов записано, слов расшифровано и потрачено на API — за неделю или за всё время.
- **Горячие клавиши** — ⌥⌘R старт/стоп записи из любого приложения, ⌥⌘V показать окно.
- **Меню-бар** — управление записью в фоне; во время записи виден красный индикатор с таймером.
- **Авто-обновления** — новые версии ставятся сами, в фоне, без сброса разрешений; ключи и токены не нужны.

## Установка

1. Скачайте [VKRec-1.6.0.dmg](VKRec-1.6.0.dmg) и откройте его.
2. Перетащите **VKRec.app** в папку **Программы**.
3. Запустите приложение и выдайте разрешения (микрофон, запись экрана и звука системы, распознавание речи).

Если macOS блокирует запуск («Приложение повреждено» / «Не удаётся проверить разработчика») — снимите карантин в Терминале и запустите снова:

```bash
xattr -dr com.apple.quarantine /Applications/VKRec.app
```

Это возможно, но происходит не всегда — зависит от того, как файл попал на ваш Mac. Команда безопасна: она лишь убирает метку «скачано из интернета». Нужна максимум один раз — обновления ставятся без карантина.

## Первая настройка

Откройте настройки (⚙️) → вкладка «Основные»:

| Параметр | Что указать |
|---|---|
| **API-ключ OpenRouter** | Для саммари, отчётов и чата: [openrouter.ai/keys](https://openrouter.ai/keys) |
| **Провайдер расшифровки** | Gladia (диалог, лучший для русского), Deepgram (диалог, быстрый) или OpenRouter (обычный текст) |
| **Язык распознавания** | Для русского выберите «Русский» явно |
| **Хранить аудио после расшифровки** | Рекомендуем включить — можно переслушивать и перерасшифровывать. Аудио в любом случае сохраняется в момент остановки; если выключено — удаляется после успешной расшифровки |
| **Предлагать запись, когда занят микрофон** | Включите, чтобы не забывать записывать звонки: панель «Записать / Не сейчас» появится сама, когда другое приложение займёт микрофон |

Рекомендуемый набор для встреч на русском: провайдер **Gladia** (Solaria-1) + ключ OpenRouter для саммари и отчётов + авто-саммари включено.

Модели для саммари, отчётов и чатов выбираются на вкладке «Саммари и отчёты». У чата на карточке и чата по записям — свои модели: первому по умолчанию назначена дешёвая GPT-5.6 Luna, второму — Gemini 3.8 Flash с большим окном контекста; там же задаётся лимит контекста чата по записям (по умолчанию 800 000 символов).

Шаблоны отчётов настраиваются на вкладке «Шаблоны отчётов»: там можно создать свой шаблон, скопировать и изменить системный, выбрать модель для конкретного шаблона, а также экспортировать/импортировать шаблоны в JSON.

Ключи провайдеров: [console.deepgram.com](https://console.deepgram.com) · [app.gladia.io](https://app.gladia.io)

## Данные и приватность

Всё хранится локально: `~/Library/Application Support/VKRec/` — записи (.json + .m4a), отчёты, свои шаблоны, теги, беседа чата по записям, журнал запросов. В облако аудио отправляется только на расшифровку выбранному вами провайдеру, текст — на саммари, отчёты и чат в OpenRouter.

## История релизов

### 1.6.0
- Чат по записям: кнопка под «Новая запись» в боковой панели — вопросы сразу к нескольким встречам. Область: «Сегодня» (по умолчанию), «Вчера», «7 дней», тег или «Выбрать записи…». Под выбором — число записей, объём и оценка стоимости вопроса; записи без готовой расшифровки в контекст не входят.
- Ответ приходит потоком и оформлен как markdown (заголовки, списки, таблицы). Модель ссылается на конкретную встречу и не смешивает решения разных встреч. Ответ можно остановить, скопировать, повторить после ошибки. Быстрые вопросы: «Что обсуждали сегодня?», «Собери задачи», «Разбей по проектам», «Саммари последней встречи».
- Лимит контекста (Настройки → «Саммари и отчёты», по умолчанию 800 000 символов): если записи не помещаются, самые длинные заменяются их саммари. Отдельная настройка «Модель для чата по записям» — по умолчанию Gemini 3.8 Flash. Под каждым ответом — модель, стоимость и время; беседа сохраняется между запусками.
- Плавающий индикатор записи стал компактнее и получил мини-режим: кнопка ⤡ сворачивает его в «линию с точкой» (точка мигает, линия дышит от громкости). Наведение курсора временно разворачивает панель; выбор вида запоминается.
- Gladia: ожидание результата зависит от длины записи (от 30 минут до 3 часов) вместо фиксированных 10 минут — длинные записи на бесплатном тарифе больше не отваливаются по таймауту; временные сбои при опросе статуса повторяются автоматически.
- Ошибки провайдеров стали понятнее: видно, кто ответил (OpenRouter, Deepgram, Gladia) и подсказка для типовых кодов (лимит запросов, неверный ключ, баланс). В записи сохраняется фактически использованная модель расшифровки.

### 1.5.0
- Таб «Чат» на карточке записи: вопросы к содержанию конкретного разговора. Модель получает всю расшифровку (с метками времени) и саммари, отвечает только по ней и прямо говорит, если тема не обсуждалась; ссылается на спикера и время. Уточняющие вопросы понимают предыдущие ответы. Enter — отправить, ⇧Enter — новая строка.
- Рекомендуемые вопросы: при первом открытии таба модель подбирает три вопроса по содержанию записи; кнопка «Другие вопросы» подбирает новые.
- Стоимость чата: под каждым ответом — модель, цена и время; сумма по чату входит в «Итого» записи и в «Статистику». При сумме больше $0.50 по одной записи — предупреждение.
- История чата сохраняется в записи; «Очистить чат», «Копировать чат», копирование отдельного ответа.
- Настройка «Модель для чата» (вкладка «Саммари и отчёты»), по умолчанию GPT-5.6 Luna.
- Карточка записи — табы «Саммари», «Отчёты», «Диалог», «Чат» вместо трёх карточек подряд. В диалоге у реплик появились таймкоды: клик перематывает плеер на реплику, звучащая реплика подсвечивается.

### 1.3.0
- Волна записи в плеере: вместо ползунка на карточке записи рисуется форма волны аудио — громкие места высокие, тишина почти линия. Клик или перетаскивание по волне — перемотка; проигранная часть подсвечивается, курсор двигается плавно. Волна считается в фоне сразу после открытия записи.
- Индикатор уровня звука во время записи: под таймером на экране «Новая запись» бежит лента уровня — сразу видно, что микрофон слышит. Такая же мини-лента добавлена в плавающий индикатор записи поверх других приложений.
- Карточка «Статистика» на экране «Новая запись»: число записей (и сколько из них диалоги), суммарная и средняя длительность, слов расшифровано, потрачено на API (расшифровка + саммари + отчёты) и число отчётов. Переключатель «Неделя / Всё время» запоминается. Карточка появляется, когда в истории не меньше трёх записей.

### 1.2.0
- Шаблоны отчётов: вместо двух фиксированных промптов («Итоги встречи» и «Задачи») — библиотека из 22 системных шаблонов в 5 категориях (Общие, Команда и Agile, Продажи и клиенты, Люди и HR, Продукт и исследования): дейлик, планирование спринта, демо, ретро, синки, встречи с клиентами, follow-up письмо, один-на-один, HR-интервью, PRD и др. «Итоги встречи» остался шаблоном по умолчанию.
- Свои шаблоны: новый раздел настроек «Шаблоны отчётов» — создание, редактирование, копирование системных, категории с цветом, иконки, поиск. Шаблон задаёт контекст встречи и разделы (название, инструкция, формат: абзац / список / таблица / письмо…); оформление приложение добавляет само. Предпросмотр итогового промпта в редакторе.
- Блок «Отчёты» на карточке записи: кнопка «Сформировать: <последний шаблон>» с меню шаблонов по категориям и окном «Все шаблоны…». Несколько отчётов можно формировать параллельно; генерация идёт в фоне и продолжается, даже если уйти с карточки.
- Отчёты сохраняются: список сформированных отчётов на карточке (шаблон, дата, модель, стоимость), просмотр без повторного запроса, «Переделать по шаблону», «Обновить», «Копировать текст», «Экспорт в PDF…», удаление. Стоимость отчётов входит в «Итого» записи.
- Автоотчёт: опция «Формировать отчёт автоматически» с выбором шаблона — запускается после первой успешной расшифровки.
- Модели: список обновлён по актуальному каталогу OpenRouter (Gemini 3.1 Pro / 3.8 Flash, Claude Sonnet 5 / Opus 5 / Fable 5.1, GPT-5.6 Sol / Luna, DeepSeek V4.1 Flash) с ценами; у шаблона можно задать свою модель поверх глобальной.
- Экспорт и импорт шаблонов в JSON — через меню раздела или перетаскиванием файла на список.
- Вкладка «Саммари» переименована в «Саммари и отчёты». Прежние промпты «Итоги встречи» / «Задачи» заменены шаблонами. При выходе из приложения во время генерации отчёта показывается предупреждение.

### 1.1.0
- Запись сохраняется всегда: сразу после остановки аудио кодируется в .m4a и запись появляется в истории — до любых сетевых запросов. Ошибка сети, неверный ключ или закрытие приложения больше не приводят к потере записи.
- Расшифровка в фоне на карточке записи: после остановки открывается карточка с индикатором прогресса, а экран «Новая запись» свободен — следующую запись можно начинать сразу. Несколько записей расшифровываются параллельно.
- Состояние расшифровки на карточке («идёт», «не завершена», «ошибка» с текстом провайдера) и кнопка «Запустить заново». Незавершённая расшифровка возобновляется при следующем запуске; при выходе во время расшифровки — предупреждение.
- Поиск по транскрипции (⌘F, ⌘G / ⇧⌘G) с подсветкой совпадений; найденная через боковую панель запись открывается с уже подсвеченными совпадениями.
- Импорт вынесен в отдельное окно «Импортировать запись…» (файлы, ссылки, корзина); ⇧⌘L открывает его с фокусом в поле ссылки. Импорт не блокирует запись.
- Настройка «Хранить аудио локально» переименована в «Хранить аудио после расшифровки»: аудио пишется всегда, при выключенной настройке удаляется после успешной расшифровки.
- Кнопка «Остановить и транскрибировать» стала «Остановить»; выбор источника звука — компактное меню.
- Если кодирование .m4a не удалось — аудио сохраняется в WAV. Расширенная диагностика в журнале; отметка об аварийном завершении предыдущего запуска в настройках.
