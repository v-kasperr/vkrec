1.О приложении

VKRec записывает звук с микрофона и/или системный звук (Zoom, Meet, Telegram-звонки), показывает живую расшифровку прямо во время записи, а после остановки делает точную расшифровку через облачные сервисы.

  • Запись — микрофон, системный звук или оба сразу.
  • Живое превью — текст появляется на экране по мере речи.
  • Точная расшифровка — Whisper (OpenRouter), Deepgram или Gladia; последние два умеют разбивать текст по спикерам (диалог).
  • Саммари — краткое резюме + автоматическое название записи.
  • Итоги встречи — красивый протокол (резюме, решения, задачи) с сохранением в PDF.
  • История — все записи с аудио, поиском, тегами и фильтрами.
  • Авто-обновления — новые версии ставятся сами, в фоне.

2.Установка

Приложение поставляется файлом VKRec-x.x.x.dmg.

  1. Откройте DMG и перетащите приложение

    Двойной клик по VKRec-x.x.x.dmg → в открывшемся окне перетащите VKRec.app на ярлык Applications.

  2. Запустите VKRec

    Откройте приложение из папки Программы или через Spotlight. При первом запуске macOS попросит выдать разрешения — см. следующий раздел.

  3. Если запуск заблокирован — снимите карантин

    В зависимости от того, как файл попал на ваш Mac, macOS может пометить его как «загруженный из интернета» и заблокировать запуск (приложение подписано самоподписанным сертификатом, не через App Store). Это возможно, но происходит не всегда. Если увидели сообщение «Приложение повреждено» или «Не удаётся проверить разработчика» — откройте Терминал (Spotlight → «Терминал») и выполните:

    xattr -dr com.apple.quarantine /Applications/VKRec.app

    Затем запустите приложение снова.

⚠️ Про команду снятия карантина Команда безопасна: она лишь убирает метку «скачано из интернета» с приложения. Нужна максимум один раз — при первой установке; авто-обновления ставятся без карантина.

3.Разрешения macOS

При первом запуске VKRec запросит три разрешения. Все они нужны для работы записи и живой расшифровки.

РазрешениеЗачем нужно
Микрофон Запись вашего голоса.
Запись экрана и звука системы Захват системного звука — то, что говорят собеседники в Zoom / Meet / Telegram. Изображение экрана не записывается, только звук.
Распознавание речи Живое превью текста во время записи (работает локально через Apple Speech).
💡 Если случайно нажали «Не разрешать» Откройте Системные настройки → Конфиденциальность и безопасность, найдите нужный раздел (Микрофон / Запись экрана и звука системы / Распознавание речи) и включите VKRec вручную. После изменения разрешения «Запись экрана» приложение нужно перезапустить.

Благодаря постоянной цифровой подписи приложения разрешения выдаются один раз — обновления их не сбрасывают.

4.Первая настройка

Откройте настройки кнопкой ⚙️ в правом верхнем углу окна. Минимум для полноценной работы — один API-ключ.

Вкладка «Основные»

  1. API-ключ OpenRouter — нужен для саммари, итогов встречи и расшифровки Whisper. Получить: openrouter.ai/keys.
  2. Провайдер расшифровки — OpenRouter (обычный текст), Deepgram или Gladia (диалог по спикерам). Для выбранного провайдера укажите его ключ и модель.
  3. Язык распознавания — для русского выберите «Русский» явно: это заметно повышает точность.
  4. Хранить аудио локально — рекомендуем включить: записи можно будет переслушивать и перерасшифровывать (~0.2 МБ на минуту).
  5. Предлагать запись, когда занят микрофон — по умолчанию выключено. Если включить, VKRec будет предлагать начать запись, как только другое приложение (Zoom, Telegram, Meet…) займёт микрофон дольше заданного времени (см. раздел «Запись»).
✅ Рекомендуемый набор для встреч на русском Провайдер Gladia (модель Solaria-1) — даёт диалог с разбивкой по спикерам; ключ OpenRouter — для саммари; язык — «Русский»; авто-саммари — включено.

5.Запись

Как записать встречу

  1. Выберите источник звука

    На экране «Новая запись»: Микрофон + система (встречи — ваш голос и собеседники), Только микрофон (диктовка), Только система (вебинар без вашего голоса).

  2. Нажмите «Начать запись»

    Или используйте горячую клавишу ⌥⌘R — работает из любого приложения. Во время записи текст появляется на экране по мере речи.

  3. Остановите запись

    Кнопка «Остановить и транскрибировать», снова ⌥⌘R или кнопка «Стоп» на плавающем индикаторе. Живой текст заменится точной расшифровкой выбранного провайдера.

Плавающий индикатор

Когда главное окно не на переднем плане, поверх всех приложений (включая полноэкранные) виден небольшой индикатор записи. Его можно перетаскивать — позиция запоминается. Клик по индикатору открывает окно VKRec, кнопка «Стоп» завершает запись.

Предложение записи при звонке

Чтобы не забывать включать запись, VKRec может сам замечать начало звонка. Включите в настройках «Предлагать запись, когда занят микрофон» — и когда другое приложение (Zoom, Telegram, Google Meet, Teams, FaceTime…) читает микрофон дольше заданного времени (по умолчанию 10 секунд), вверху экрана поверх всех окон появится панель с названием приложения и кнопками «Записать» и «Не сейчас».

  • «Записать» — запись стартует сразу с текущим источником звука, переключаться в VKRec не нужно.
  • «Не сейчас» — панель прячется и не появляется заданное время (по умолчанию 10 минут). Если панель проигнорировать, через минуту она скроется сама.
  • Когда приложение освобождает микрофон (звонок закончился), панель исчезает; для следующего звонка предложение появится снова.

Функция не требует дополнительных разрешений и ничего не записывает сама: VKRec лишь смотрит, какой процесс использует микрофон. Некоторые приложения держат микрофон открытым и вне звонка (например, Discord с голосовой активацией или вкладка браузера с разрешённым микрофоном) — в этом случае предложение может появляться без звонка; тогда увеличьте задержку или отключите функцию.

💡 Длинные записи Запись длиной в час и больше — не проблема: аудио автоматически режется на части и расшифровывается по очереди с показом прогресса. Gladia обрабатывает асинхронно (~1 минута на час аудио).

6.Горячие клавиши и меню-бар

СочетаниеДействие
⌥⌘RНачать / остановить запись — не переключаясь из текущего приложения
⌥⌘VПоказать окно VKRec на текущем экране

Сочетания работают глобально — даже когда вы в Zoom или браузере.

Иконка в меню-баре

VKRec живёт в строке меню (справа вверху экрана): старт/стоп записи, открытие окна, индикатор доступного обновления и выход. Закрытие главного окна не завершает приложение — запись продолжается в фоне.

7.История и карточка записи

Левая панель — шапка с поиском и кнопкой «Новая запись», ниже — история. В строке записи: число спикеров (👥 2), название, дата, длительность, значок ✨ у записей с саммари и тег.

Поиск и фильтр

  • Поиск — по названию и тексту расшифровки.
  • Фильтр по тегам — кнопка слева от поиска: все записи, без тегов или конкретный тег. Активный фильтр показан чипом в строке поиска, сброс — по ✕.

Карточка записи

БлокЧто можно делать
Заголовок Кликните и отредактируйте. Сохраняется по Enter или при уходе фокуса. При генерации саммари название подставляется автоматически.
Метаданные Дата, длительность, источник, язык и суммарная стоимость обработки ($).
Теги Кнопка + Тег открывает выбор цветных чипов (см. раздел 9).
Аудио Встроенный плеер: воспроизведение, перемотка, тайминги (если включено локальное хранение).
Саммари Генерация / обновление резюме, копирование.
Итоги встречи Протокол в PDF (см. раздел 8).
Транскрипция / Диалог Полный текст. Для Deepgram/Gladia — в виде диалога: Спикер 1, Спикер 2… Кнопка «Запустить заново» перерасшифровывает аудио текущими настройками — удобно, если сменили провайдера.

В панели инструментов карточки: Экспорт (текст + саммари в .txt) и Удалить. Удалить запись можно также правым кликом в списке истории.

8.Саммари и итоги встречи

Саммари

Краткое резюме: 1–2 предложения сути + ключевые пункты списком. Вместе с саммари модель придумывает название записи — оно заменяет техническое название из первых слов расшифровки (название всегда можно поправить вручную).

  • Автоматически после каждой записи — включите «Делать саммари автоматически» в настройках (вкладка «Саммари»).
  • Вручную — кнопка «Сгенерировать саммари» в карточке записи.
  • Модель выбирается в настройках; по умолчанию GPT-4o mini — быстро и дёшево.

Итоги встречи (PDF)

Кнопка «Сформировать итоги встречи» генерирует полноценный протокол: резюме, принятые решения, задачи с ответственными, таймлайн. Результат сохраняется в PDF и показывается в Finder.

  • Модель для итогов настраивается отдельно (по умолчанию Gemini 3.1 Pro — сильна в вёрстке).
  • Промпт протокола можно отредактировать под свои стандарты (вкладка «Саммари» → «Промпт для итогов встречи»), есть кнопка сброса к стандартному.
💡 Стоимость Цена каждой операции видна прямо в приложении: рядом с саммари и суммарно в шапке карточки. Обычно саммари стоит доли цента.

9.Теги

Теги помогают организовать записи: ВК 1-на-1 Планёрка

  1. Создайте теги — Настройки → вкладка «Теги»: название + один из 8 цветов. Там же теги можно переименовать или удалить.
  2. Назначьте на запись — в карточке записи нажмите + Тег и кликайте по чипам: клик добавляет или убирает тег, окно остаётся открытым для выбора нескольких. Снять тег можно и по ✕ на его пилюле.
  3. Фильтруйте историю — кнопка фильтра слева от поиска: у каждого тега виден счётчик записей.

10.Провайдеры расшифровки

ПровайдерДиалог по спикерамКогда выбирать
OpenRouter (Whisper) Нет Диктовки и монологи. Один ключ и для саммари, и для расшифровки.
Deepgram Да Быстрая расшифровка встреч. Ключ: console.deepgram.com.
Gladia Да Лучший выбор для русского (модель Solaria-1). Асинхронная обработка: ~1 мин на час аудио. Ключ: app.gladia.io.

Провайдера можно менять в любой момент — а старые записи перерасшифровать кнопкой «Запустить заново» в карточке (нужно включённое локальное хранение аудио).

Журнал запросов

Все обращения к ИИ-сервисам пишутся в файл (без аудио-данных) — полезно при разборе проблем. Открыть: Настройки → «Основные» → «Открыть журнал».

11.Обновления

VKRec проверяет обновления автоматически раз в час и обновляется сам — DMG нужен только для первой установки.

  • О новой версии сигналят: модальное окно, зелёная кнопка в панели инструментов и пункт в меню-баре.
  • Установка бесшовная: версия скачивается в фоне, приложение перезапускается само. Разрешения не сбрасываются.
  • Проверить вручную: Настройки → «Обновления» → «Проверить обновления». Там же виден номер текущей версии.
  • Никаких ключей и токенов для обновлений не нужно — сборки публикуются в открытом репозитории.
✅ Карантин снимать больше не придётся Если команда xattr понадобилась при первой установке из DMG — больше она не нужна: авто-обновления ставятся без карантина.

12.Частые вопросы

«Приложение повреждено» или «Не удаётся проверить разработчика»

macOS пометила приложение карантином при загрузке (случается не всегда — зависит от способа передачи файла). Выполните в Терминале и запустите приложение снова:

xattr -dr com.apple.quarantine /Applications/VKRec.app

Не слышно собеседников в записи

Проверьте: источник — «Микрофон + система», и разрешение «Запись экрана и звука системы» выдано (Системные настройки → Конфиденциальность и безопасность). После выдачи разрешения перезапустите VKRec.

Живой текст не появляется во время записи

Не выдано разрешение «Распознавание речи», или речь идёт не на выбранном языке. Живое превью — черновик: точный текст появится после остановки записи.

Расшифровка не запускается после остановки

Проверьте API-ключ выбранного провайдера в настройках. Детали ошибки — в журнале запросов (Настройки → «Основные» → «Открыть журнал»).

Плохое качество расшифровки на русском

Выберите язык «Русский» явно (не «Авто») и попробуйте провайдера Gladia с моделью Solaria-1.

Где хранятся мои данные?

Всё локально: ~/Library/Application Support/VKRec/ — записи (.json + .m4a), теги и журнал. В облако аудио отправляется только на расшифровку выбранному провайдеру.

Запись остановилась при закрытии окна?

Нет — приложение продолжает записывать в фоне. Управляйте через меню-бар, плавающий индикатор или ⌥⌘R.
